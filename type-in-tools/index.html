Type in each tool

The typefaces as files. What each font is called in a menu, how to install it, how it travels with a file, and what steps in when it is missing.

What the fonts are called.

The same font shows under a different name on Windows and on a Mac.

UseIn a Windows font menuIn a Mac font menu
TitlesOutfit SemiBoldOutfit, style SemiBold
Names and buttonsOutfit MediumOutfit, style Medium
Reading textOutfitOutfit, style Regular
LabelsManrope SemiBoldManrope, style SemiBold
The one italic asideInstrument Serif, italicInstrument Serif, style Italic
The name in ArabicNoto Naskh ArabicNoto Naskh Arabic
  • Pick the weight by its name. Never press Bold on Outfit: the program fakes it.
  • The templates already hold the right font in every text box.

Installing.

Install the fonts once, and every desktop program can use them.

  • Windows. Open the font folder, select the files, right-click, and choose Install.
  • Mac. Open the files in Font Book and choose Install.
  • Google Slides and Docs. Nothing to install. In the font menu, choose More fonts, and search for Outfit and for Manrope.
  • Restart PowerPoint, Word, or Keynote after installing, so the fonts appear.

Embedding.

A file opened on a computer without the fonts falls back to Arial, unless the fonts travel with it.

  • PDF. The fonts are carried inside the file. Send a finished piece as a PDF.
  • PowerPoint and Word. In the save options, turn on "Embed fonts in the file" before sending an editable file.
  • Google Slides and Docs. The fonts are online, so every viewer sees them.
  • Keynote. It does not embed fonts. Send a PDF, or make sure the receiver has installed them.

The fallback.

Arial steps in where Outfit and Manrope are missing. It is on every computer, so the layout holds.

  • It is the stand-in, never a choice. Nothing khyzr designs is set in Arial on purpose.
  • The one place it is correct by design is the text of an email, which cannot carry a font.
  • If a deck looks plain and wide, the fonts are missing. Install them and open it again.

The font files.

One folder for each family.

  • Outfit at its three weights, Manrope at semibold, Instrument Serif in regular and italic, Noto Naskh Arabic at regular and semibold.
  • A file is named by family and weight: Outfit-600.ttf, InstrumentSerif-400Italic.ttf.
  • On the web the fonts are served by Google Fonts. The files are in the Drive's Fonts and color folder, and in the brand kit.
