# khyzr: brand and design system

**https://khyzr-creative.github.io/design-system/**

Everything starts here. One source with two doors: the brand, for everyone, and the design system, for builders.

- **Brand.** For everyone. Who khyzr is, and how it looks and sounds anywhere: the brand and its voice, the logo, color, type, backgrounds, imagery, icons, and data, the house and its two products, and the brand in use.
- **Design system.** For builders. Every value by its token, the foundations, motion, the components and forms, the pattern elements, documents in code, and the three sites as built.

This repository is the built site and nothing else. Every file in it is generated from the khyzr design system and replaced whole on each build, so a change made here is overwritten.
