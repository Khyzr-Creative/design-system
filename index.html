How to use this.

  • New here? Begin with Start here: the few rules that matter most, and where the files are.
  • Logos are used as files. Never redraw a mark, recolor it, or compose symbol and name by hand. The one exception is the logo pattern, a background made from the symbol's shapes: it is a pattern, not a mark (see Backgrounds and Logos).
  • Tokens are the values. Color, type, spacing, radii, and motion are set in the token files. Where any prose disagrees with a token, the token wins. They are behind the design system's door, on Tokens.
  • This site is built from the system's own files. Every swatch, specimen, download, and live component here is generated from them. Nothing is copied by hand, so nothing can drift.
  • It is a working system. Where something has no answer yet, it says so.
