Assets in code

The marks, the icons, the fonts, and the pictures as files in a page: where each lives, which file a job takes, and how an icon takes its color and its size. Which mark and which icon to use is in the brand's Logos and Icons chapters.

Where things live

Everything a page needs is under design-system/.

FolderWhat it holds
tokens/The five token files. A page links design-system/styles.css, which imports them
assets/logos/khyzr's marks as SVG, with reg/ for the ® set, png/ for the favicon and app-icon files, and products/ for the two products
assets/icons/The fifteen icons, in utility/ and illustrative/
assets/pattern/The two pattern elements
assets/backgrounds/The stills of the backgrounds, the share card, and the avatars
  • The SVG set here is the working set for a screen. The full packs, with PDF, EPS, the PNG sizes, and the print-color files, are on the Logo files page.
  • This site serves only the files its pages show or offer. A file not linked on a page is in the design system's folder.

Logos

Logos are used as files. Never redraw a mark, recolor it, or compose a symbol and a name by hand.

  • Size a mark by its width, and let its height follow. The wordmark is never under 90px wide on a screen.
  • Give an image of a mark its name as alt text: alt="khyzr". A mark that repeats beside the same name in text takes an empty alt.
  • The name stays lowercase in meta, alt, and aria text, as it does in copy and in the names of files and folders. Code and the GitHub organization keep the spelling they were made with.
  • A mark that changes with the ground is two files, one above the other, crossfaded. Never a filter on one file.
  • A file's name says what it is: {brand}-{mark}_{ground}_{variant}. The brand is khyzr, khyzr-ai, or khyzr-studio.

Product marks

  • Each product has the same set under assets/logos/products/: the wordmark on dark, on light, black, and white; the icon on dark and on light; its two badges; and its favicon.
  • A product's favicon keeps its deep tile in every theme.
  • A product's PNG and .ico files are in products/png/, named as khyzr's are.
  • A product wordmark is khyzr's wordmark, its paths unchanged, followed by .ai or .studio in Outfit at 500, outlined. The x-heights match, the suffix is tracked −.02em, and both sit on the wordmark's baseline.

Icons

Two sets from one family, Solar. Nine line icons do work in an interface, and six two-tone icons mark a moment.

DrawingA 24 grid, one stroke at 1.5The same grid and stroke, with a second layer at 50% opacity
Size16 to 24px32px or larger
Color on lightink, or bodyforest
Color on darkWhite, or green-300green-300
  • Every file is 1em wide and high, and draws in currentColor. Set an icon's size with font-size, or with a width and a height, and its color with color.
  • An icon inherits its color only when its SVG is in the page. Placed as an image, it draws in black: inline it, or use it as a mask.
  • The second layer of an illustrative icon is part of the file, at 50% of the icon's own color. One file carries two layers, at 40% and 70%. Never recolor a layer on its own.
  • An icon beside words is decoration: aria-hidden="true". An icon alone in a control needs a label on the control.
  • An icon follows the weight of the type beside it. It never takes a fill, a shadow, or a secondary color.

Arrows

  • A row or a link takes arrow-right. It slides 4px on hover, on ease-pop.
  • A link that leaves the site takes arrow-right-up.
  • A previous control takes arrow-right, mirrored.
  • Both replace the typed arrows. No typed character stands in for an icon.

Fonts

  • One stylesheet loads the faces: tokens/fonts.css, which styles.css imports first.
  • It loads Outfit at 400, 500, and 600, Manrope at 600, Instrument Serif, and Noto Naskh Arabic at 400 and 600. There is no monospace.
  • A page that sets another weight loads it itself. khyzr.com loads Manrope at 500 for one label.
  • Name a face through its token, font-display, font-text, font-tech, font-serif, or font-arabic, so the fallbacks travel with it.

Pictures

  • Backgrounds. The stills are in assets/backgrounds/, named by background, look, job, and size. The pattern elements page lists them.
  • Photographs. The grade is baked into the file before it goes in: saturation at 88%, contrast at 102%. No filter runs on a page.
  • A photograph in a panel takes radius-m or radius-l. Full bleed, it takes none.
  • Every picture states its width and height, so the page does not move when it arrives.
