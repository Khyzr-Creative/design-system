Outfit is khyzr's typeface: geometric, tight, calm. It sets everything a person reads at length or at a glance.

  • Outfit. Titles, statements, reading text, buttons, captions. Three weights, by role.
  • Manrope. Small labels only: uppercase, widely tracked, never a sentence.
  • Instrument Serif. One italic aside, lowercase, at most once on a page. The rarest of the four: none of the three sites uses it.
  • Noto Naskh Arabic. The name, الخضر, in its one moment. Nowhere else.
  • There is no monospace.

Weight is set by the job a line does, never by eye.

  • Semibold for titles, numbers, and quotes.
  • Medium for names inside cards and lists, and for buttons.
  • Regular for reading.
  • Emphasis inside reading text is semibold, never italic.

How a headline is set.

A khyzr headline is a sentence in ink: tight, left aligned, sentence case, ending with a period.

  • One green phrase, at most. The payoff, usually the last words. In "Every discipline. One team.", the green falls on "One team."
  • Tight up top, open below. Large type tracks tight, and tighter as it grows. Labels track wide. Reading text stays neutral.
  • Small beside large. Supporting text is small and gray, on a short line, about a third the size of its title. It never competes.
  • Uppercase belongs to the labels only.

Labels.

The one place khyzr uses uppercase. A label names a thing: a caption under a number, a column head, a page's folio.

  • Manrope, semibold, uppercase, widely tracked.
  • Small, and never smaller than 11px on a screen.
  • Never a sentence, and never a headline.
  • khyzr.ai and khyzr.studio set their labels in Outfit and use no Manrope.

When Outfit is missing.

Arial steps in. It is on every computer, so a file opened without khyzr's fonts still holds its layout.

  • Arial is the stand-in, never a choice. A piece khyzr designs and sends is set in Outfit.
  • It is right where fonts cannot travel: an email's own text, a shared file on someone else's computer.
  • Send a finished piece as a PDF, which carries its fonts with it.
  • How to install the fonts and embed them is in Type in each tool.
